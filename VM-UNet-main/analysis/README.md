# 分析脚本

研究分析脚本都放在这里并提交，比如标签统计、配对差检验、后处理模拟和论文图表的数据准备。约定如下：

- **文件命名：** `<主题>.py`，与对应的 IDEA 或 EXP 用文件名、或文件头注释关联起来。
- **文件头注释必须写明三件事：**
  - 读取了哪些输入；
  - 使用了哪些数据集划分（**不得使用 test**，FINAL 任务除外）；
  - 产物写到哪里。
- **只读不写：** 只读取 `results/`、`research/experiments/` 和原始数据，不修改它们。产物写到 `results/analysis/`，该目录不入库。
- **结论去向：** 分析结论写进对应的 IDEA 或 EXP 报告，并注明产生结论的脚本名。
