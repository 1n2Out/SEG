使用 [brats2020.json](../VM-UNet-main/configs/brats2020.json)：**全切片、最多 60 轮，GPU 2（RTX 6000 Ada），batch=8、workers=4、AMP 开启**。随机初始化，保留全部 40,145 张训练切片，每轮 5,019 批。

第 1 轮及每 5 轮验证，早停保持 `patience=10`、`min_delta=0.0001`，余弦调度 `T_max=60`。baseline、改进与消融共用协议。预计约 7.3 小时，排期预留 **8–10 小时**，依据见 [耗时记录](TRAINING_TIME_gpu2_2026-11-02.md)。

## 训练、恢复与测试

```bash
# 前台训练；后台运行则使用下一条命令，二选一。
python run_brats.py
python run_brats.py --background

# 查看后台训练进程及日志。
ps -p "$(cat logs/brats2020.pid)" -o pid,etime,args
tail -f logs/brats2020.log

# 中断训练
# 先确认这是本次 train_brats.py 训练进程
ps -p "$(cat logs/brats2020_20261102_165024_818461.pid)" -o pid,etime,args
kill -TERM "$(cat logs/brats2020_20261102_165024_818461.pid)"

# 中断后恢复，前台或后台二选一。
python run_brats.py resume
python run_brats.py resume --run-dir results/brats2020_日期时间 --background

# 方法和超参数确定后，使用正式 best.pth 评价测试集。
python run_brats.py test --run-dir results/brats2020_日期时间
```

续跑必须使用原配置、原工作目录和原卡数，不可修改总轮数后直接续跑。测试需要正式训练生成的 `results/brats2020/best.pth`，验收权重不能替代。
