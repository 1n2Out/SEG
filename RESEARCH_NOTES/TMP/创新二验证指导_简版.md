# 创新二验证（简版）

完整版：[创新二验证指导.md](创新二验证指导.md)。所有命令都在服务器的 `VM-UNet-main/` 下执行。

## 1. 检查（约 30 分钟）

```bash
python -m pytest -q tests/test_detail_fusion.py tests/test_warm_start.py
CUDA_VISIBLE_DEVICES=<空闲卡> python -m pytest -q tests/test_detail_fusion_cuda.py   # 必须 passed，skipped 不算
ls results/brats2020_1102_1734/best.pth                                              # 热启动来源权重
```

把 `configs/screening/` 下四个配置的 `launch.gpus` 分别改到不同的单张空闲卡（现在都是 `[2]`）。然后每个配置跑一次 smoke：

```bash
python run_brats.py smoke --config configs/screening/<name>.json
```

通过标准：四个配置在第 1 例上的 Dice 基本一致（因为零初始化，起点与 baseline 相同）。

## 2. 筛选（10 轮热启动，约 1.5 小时，四卡并行）

```bash
python run_brats.py train --config configs/screening/baseline.json      --background  # 对照，必跑
python run_brats.py train --config configs/screening/detail_gated.json  --background  # 主方案，必跑
python run_brats.py train --config configs/screening/detail_concat.json --background  # 门控消融
python run_brats.py train --config configs/screening/shallow_gated.json --background  # 只补 1/4 尺度
```

比较第 10 轮的 `validation/epoch_010/summary.json` 和 `per_patient.csv`。detail_gated 与 baseline 相比：

| 结果 | 决策 |
| --- | --- |
| Mean Dice 至少 +0.5，ET 上升，HD95 没有变差，空 ET 假阳性没有增加（baseline 为 2/5） | 进入第 3 步 |
| 提升不到 0.5 | 视为噪声，先看非空 ET Dice 是否稳定为正 |
| 没有提升 | 停止，记录负结果 |

其他对比只影响论文叙事：gated 好于 concat 说明门控有效；detail 好于 shallow 说明更高分辨率才是关键。

## 3. 正式训练与测试（约 11 小时）

```bash
python run_brats.py train --config configs/detail_fusion/gated.json --background
python run_brats.py test  --config configs/detail_fusion/gated.json --run-dir results/<训练目录>
```

先与 EXP-001 的验证结果比较（第 55 轮，81.78%），确定方法之后才评价测试集，且只评价一次。消融行（concat、shallow）也按正式协议各跑一次。结果写入 `EXPERIMENTS_BraTS.md` 和 `INNOVATIONS.md`。

中断后续训：`python run_brats.py resume --config <配置> --run-dir <训练目录> --background`
