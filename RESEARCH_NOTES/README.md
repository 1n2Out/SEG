# RESEARCH_NOTES 使用与维护约定

本目录保存用户的研究笔记、操作指南、实验记录与必要的验收依据。

## 修改限制

**除非用户明确要求修改本目录文档，否则不得修改 `Seg/RESEARCH_NOTES/` 及其任何子目录中的文档。本 README 同样受此限制。**

- 可以阅读、检索和引用已有文档。
- 未经用户明确要求，不得新增、改写、追加、删除、重命名或移动本目录中的文档。
- 用户要求修改代码、配置、运行训练或分析结果，不自动授权同步更新本目录，包括 HISTORY、个人指南、实验记录等。
- 不得以“保持一致”“补充记录”“更新进度”“整理文档”为由自行修改；可以在回复中说明建议，等待用户明确提出文档修改要求后再执行。
- 用户明确要求修改时，仅处理该请求涉及的文档和内容；一次授权不代表后续持续授权。
- 代码运行产生的日志、计时报告、预测和临时文件放在源码目录的 `results/` 等输出位置，不自动写入本目录。

本次用户明确要求的目录清理与 README 创建属于已授权操作。
