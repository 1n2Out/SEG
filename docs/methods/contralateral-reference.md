# 对侧半球参照的多模态差异融合

[IDEA-011 设计依据](../../research/ideas/idea-011-contralateral-reference.md) · [B 端任务单](../../handoff/task-009-contralateral-full.md) · [正式配置](../../VM-UNet-main/configs/detail_fusion/contralateral.json)

## 输入和解剖方向

使用现有四模态、单张轴向切片缓存。根据每名患者的 NIfTI affine 识别左右轴，以未补零图像的数组中心近似中线。在每个模态内，用本侧标准化强度减去镜像位置强度，保留符号。参考是近似解剖对应，跨中线、占位变形和正常不对称均可能影响差值。

数据加载时先生成四张差值图，与原图一起旋转、翻转和补零。整例推理按患者采用相同轴与差值定义，再做补零和切片分批。缓存、主干和原细节支路均使用原四个模态；送入模型的八个平面为四张原图和四张派生图。标签只参与监督或离线诊断。

## 结构和初始化

1. 差值图经 2×2 平均池化到 1/2 尺度，再经 3×3 卷积、GroupNorm 和 GELU 得到 32 通道差异特征。
2. 与已有的 1/2 融合语义拼接，经过 1×1 卷积及 sigmoid 得到单通道空间门控。门控逐位置调节差异特征。
3. 以 1×1 卷积将门控特征投影并加回 1/2 融合语义，再走原有 1/1 解码。投影权重初始为零。共享参数的初值、主干调用次数和训练损失沿用 gated 配置。

正式配置使用 `detail_fusion.contralateral: true` 和 `mode: "gated"`。关闭或省略该选项可加载原 gated 配置。相对 EXP-006 新增 2,305 个参数，总计 27,501,939 个。新增投影和原细节头均为零初始化，完整训练的第一步更新原细节头，第二步梯度到达新增投影，第三步到达差异卷积和门控。

## 工程验证

CPU 检查覆盖两种平面左右轴、四种直角旋转、翻转、非对称补零、整例分批推理、val 与训练数据的一致性、初始等价、配置差异和梯度。B 端用真实 selective scan 和 AMP 检查完整网络的初始等价、反传及权重重载，再按任务单进行正式尺寸的 smoke。
